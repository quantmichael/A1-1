# Prompt Manager

Python과 Git을 활용한 콘솔 기반 프롬프트 관리 프로그램입니다.

---

## 프로젝트 소개

프롬프트를 효율적으로 관리하기 위한 콘솔 프로그램입니다.

사용자는 프롬프트를 추가하고,
검색하고,
카테고리별로 조회하고,
즐겨찾기를 관리할 수 있습니다.

---

## 개발 환경

- Python 3.14
- Git
- Visual Studio Code

---

## 실행 방법

```bash
python main.py
```

---

## 주요 기능

### 1. 프롬프트 추가

- 제목 입력
- 내용 입력
- 카테고리 선택

### 2. 프롬프트 목록 조회

- 전체 목록 출력
- 즐겨찾기 표시

### 3. 카테고리별 조회

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

### 4. 프롬프트 검색

- 제목 검색
- 내용 검색

### 5. 프롬프트 상세 보기

- 제목
- 내용
- 카테고리
- 즐겨찾기 여부

### 6. 즐겨찾기 관리

- 추가
- 해제

### 7. 즐겨찾기 목록

- 즐겨찾기만 조회
